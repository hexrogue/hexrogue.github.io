Things I built and maintain. Some are private client work, summarized without source links. Some are open source, with the code and the mistakes left in public. All of them were built to solve a real problem, not to fill a portfolio grid.

The flagship is [APEL.A](/projects/apela/), the first APEL.A admissions system in Malaysia. Around it: the admissions CRM, the WhatsApp gateway, the internal operations platform, and the smaller open-source and hardware projects that keep the rest honest.

The interesting part is rarely the framework. It is the constraint: a team that needs the workflow to be simpler, a device that refuses to cooperate, or a system that has to keep working when the network does not.
